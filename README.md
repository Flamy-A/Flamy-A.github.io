# Amio Rashid — Portfolio

A lightweight, responsive personal portfolio for GitHub Pages, adapted from the structure of [Jon Barron's academic website](https://jonbarron.info/).

## Publish on GitHub Pages

1. Push these files to the repository named `Flamy-A.github.io` (or your chosen Pages repository).
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, then select the branch and `/ (root)` folder.

The site uses plain HTML and CSS and does not require a build step.
